代理资源
代理池管理与可用性检测

        
      


      
      

        📖 静态代理池教程展开 / 收起
        

          
静态代理池 = 固定代理列表，适合没有动态代理 API 时使用。任务取代理时优先用已配置的动态代理 Provider，没有才回退到这里的静态池。

          

            

              
① 格式

              
每行一个，右侧「新增代理」框批量粘贴即可：

              
http://user:pass@host:port
http://1.2.3.4:8080          # 无需账密的代理
socks5://user:pass@host:port

              
可选填地区标签（US / SG…），注册时会按目标地区筛选可用代理。

            

            

              
② 怎么被用到

              
    
                
  • 任务发起时按成功率加权轮询取一个代理，成功率高的更容易被选中；
    • 
                
  • 代理连续失败会被自动降低权重，反复失败自动禁用（状态栏可看）；
    • 
                
  • 勾选了地区的代理只服务对应国家的注册；地区留空则不挑。
    • 
              

              
③ 检测

              
顶部「⟳ 检测全部」批量测活，列表每条的“成功/失败”列实时累计，帮你看哪些代理已经被风控、该删掉换新。
